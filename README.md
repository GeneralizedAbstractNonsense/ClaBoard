<p align="center">

<p align="center">




Multi-page digital whiteboard for writing, drawing, and presenting lessons. Includes pens and erasers, shapes, interactive charts, image and PDF import, PDF export, and geometry tools.

## Download desktop

You can download the last version on [Releases Page](https://github.com/GeneralizedAbstractNonsense/ClaBoard/releases):

- [macOS — Apple Silicon e Intel](https://github.com/GeneralizedAbstractNonsense/ClaBoard/releases/latest)
- [Windows — installer](https://github.com/GeneralizedAbstractNonsense/ClaBoard/releases/latest)
- [Linux — AppImage and DEB package](https://github.com/GeneralizedAbstractNonsense/ClaBoard/releases/latest)




Desktop builds are generated for macOS, Windows and Linux when a tag `v*` is published. 

## Local development 

```sh
npm ci
npm run dev
```

Use `npm run build` to create the bundle; it is possible to use`npm run tauri:build` in order to build the package on your platform.
